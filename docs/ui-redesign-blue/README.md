# 雕雕助手 · 方案二：雾蓝与暖灰白

[打开独立 HTML](../app-ui-redesign-blue.html) · [原青绿色方案](../app-ui-redesign.html)

原稿及其源文件保留不动；本目录是独立副本，沿用 53 个页面／浮层、78 个状态和交互。

## 配色依据

自动化工具需要长时间阅读列表、代码和日志。采用低饱和雾蓝控制视觉刺激，暖灰白减少大面积纯白的生硬感，深蓝灰保证信息密度较高时的识别度。保留原棕金色雕雕图标，用少量沙色与它呼应。全稿不使用紫色，包括原来的淡紫任务图标。

| 角色 | 色值 | 使用位置 |
| --- | --- | --- |
| 雾蓝 | `#3566A0` | 主按钮、选中态、可操作文字 |
| 深蓝灰 | `#223047` | 标题、品牌区域、悬浮控制条 |
| 暖灰白 | `#FAF9F6` | 手机页面底色 |
| 白 | `#FFFFFF` | 卡片、表单、底部导航 |
| 淡雾蓝 | `#EDF2F8` | 说明、选项与工具底色 |
| 沙色 | `#EBD9B4` | 少量品牌点缀，呼应雕雕形象 |
| 次级文字 | `#616E80` | 说明和辅助信息 |
| 成功 | `#36735B` | 成功、服务正常、权限就绪 |
| 警告 | `#94601F` | 等待、覆盖、权限提示 |
| 错误 | `#AE4647` | 失败、删除和危险操作 |

状态色与品牌主色分工明确，文字和图标同时传达状态。目标应用示意截图和取色样本属于示例内容，保留其原始颜色。
