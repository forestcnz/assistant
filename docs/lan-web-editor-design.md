# 局域网 Web 编辑器设计

日期：2026-11-06

## 1. 目标

在 Android App 内启动一个仅限局域网访问的 Web 服务。同一局域网中的电脑、平板和手机可以通过浏览器编辑任务，不需要安装额外客户端。

首版覆盖：

- 浏览和新建脚本任务、流程任务。
- 在任务设置中重命名、编辑描述与目标应用、设置整任务循环和设计尺寸，或删除任务。
- 编辑任务入口脚本 `task.js`。
- 编辑可视化流程 `flow.json`，保存时继续由现有编译器生成 `task.js`。
- 添加点击、滑动、等待、日志、顺序组、循环、条件分支、找图和找字模块。
- 在浏览器中选择图片并上传到当前任务的 `images/` 目录。
- 在素材管理中批量上传、预览、下载、重命名和删除图片。重命名会同步脚本、流程及草稿中的文件名引用。
- 在浏览器中框选或输入像素坐标裁剪图片。保存后替换当前素材，原图进入与 App 共用的历史素材，可移回并覆盖当前同名文件。
- 流程代码预览与保存前校验。
- 桌面三栏布局和手机单列布局。

## 2. 运行结构

```text
局域网设备浏览器
        │ HTTP
        ▼
LanWebService（Android 前台服务）
        │
        ▼
LanWebServer（嵌入式 NanoHTTPD）
        │
        ├── 静态 Web UI
        └── 任务 REST API
                │
                ▼
        TaskManager / FlowCompiler
                │
                ▼
    tasks/<任务>/task.js、flow.json、images/
```

服务固定监听 `8765` 端口。App 设置页提供启动、停止、复制访问地址和运行状态展示。

## 3. 访问控制

- 访问地址格式为 `http://<局域网IP>:8765/`，不需要访问令牌或查询参数。
- 同一局域网内能访问该地址的设备均可读取和编辑任务，应仅在可信网络中使用。
- 服务不会直接暴露任务目录路径；所有任务名必须与 `TaskManager.listTasks()` 返回的名称完全匹配。
- 图片读取和删除只允许任务 `images/` 目录的直接子文件。

## 4. Web 界面

### 4.1 桌面与平板

```text
┌──────────────────────────────────────────────────────────────┐
│ 品牌 / 局域网状态                        已保存  预览  保存  │
├──────────────┬──────────────────────────┬────────────────────┤
│ 任务列表     │ 流程画布                  │ 步骤参数            │
│ 搜索/新建    │ 顺序、循环、条件与分支     │ 当前步骤表单        │
│ 拖动任务排序 │ 拖动把手调整顺序           │ 图片选择与上传      │
└──────────────┴──────────────────────────┴────────────────────┘
```

### 4.2 手机

- 任务列表改为侧滑抽屉。
- 流程画布和步骤参数上下排列。
- 模块库使用弹层，点击模块添加到当前插入位置。
- 任务卡片整体可拖动；触屏长按后开始拖动，普通滚动不会误触排序。流程步骤仍用左侧把手排序。

### 4.3 流程画布

- 流程显示在可平移、缩放的点阵画布上；平移和缩放只影响视图，步骤仍按流程顺序运行。
- 桌面拖动画布空白处平移，滚轮移动画布，按住 Ctrl / Command 滚动可缩放。触屏可拖动平移或双指缩放。
- 工具栏提供放大、缩小、适应画布和回到起点。
- 模块库采用独立卡片，点击即可添加；桌面可拖到插入线、循环体或条件分支。

## 5. 编辑模型

Web 编辑器直接读写现有文件格式，不引入第二套任务格式：

- 脚本任务：编辑 `task.js`。
- 流程任务：编辑 `flow.json`，保存时调用 `FlowCompiler.save()`。
- 整任务执行次数写入 `config.json.loop`。
- 图片上传后只把实际文件名写入节点，编译器负责转换为 `images/<文件名>`。

找图和找字默认“仅识别”。需要点击时，在“命中后”中显式选择“点击命中位置”。

## 6. API

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| `GET` | `/api/tasks` | 任务列表（按保存的拖拽顺序，含 `orderRevision`） |
| `POST` | `/api/tasks` | 新建脚本或流程任务 |
| `PUT` | `/api/tasks/order` | 保存任务列表拖拽顺序，需携带 `If-Match` 版本 |
| `GET` | `/api/tasks/{name}` | 读取任务类型、流程源和可编辑的最终 `task.js` |
| `PUT` | `/api/tasks/{name}` | 保存任务设置，可同时重命名任务 |
| `DELETE` | `/api/tasks/{name}` | 删除任务及其定时设置 |
| `PUT` | `/api/tasks/{name}/script` | 保存 `task.js`；流程任务保存后转换为普通脚本任务 |
| `GET` | `/api/tasks/{name}/flow` | 读取流程草稿或正式流程 |
| `PUT` | `/api/tasks/{name}/flow` | 校验并保存流程 |
| `POST` | `/api/tasks/{name}/validate` | 编译并返回 `task.js` 预览 |
| `GET` | `/api/tasks/{name}/images` | 列出任务素材 |
| `POST` | `/api/tasks/{name}/images` | Base64 上传素材 |
| `GET` | `/api/tasks/{name}/images/{file}` | 读取素材 |
| `PUT` | `/api/tasks/{name}/images/{file}` | 重命名素材并同步引用 |
| `POST` | `/api/tasks/{name}/images/{file}/rename-preview` | 预览重命名涉及的脚本和流程引用 |
| `DELETE` | `/api/tasks/{name}/images/{file}` | 删除素材 |
| `GET` | `/api/tasks/{name}/images/{file}/crop` | 读取裁剪预览和原图尺寸 |
| `POST` | `/api/tasks/{name}/images/{file}/crop` | 保存裁剪并归档原图 |
| `GET` | `/api/tasks/{name}/image-history` | 列出历史素材 |
| `GET` | `/api/tasks/{name}/image-history/{id}` | 预览历史原图 |
| `POST` | `/api/tasks/{name}/image-history/{id}/restore` | 将历史素材移回当前素材 |

所有写操作都检查脚本运行状态。任务运行期间禁止通过 Web 保存，避免覆盖正在执行的脚本。

## 7. 文件安全

- 脚本大小上限 2 MB。
- 单张图片上限 15 MB。
- 文件名去除路径和非法字符；重名时自动增加 `_1`、`_2` 后缀。
- 流程保存沿用 `FlowCompiler` 的节点数量、ID、嵌套深度、循环和识别参数校验。
- 使用 `AtomicFile` 写入脚本和流程文件。

## 8. 后续扩展

- 二维码展示访问地址。
- 局域网设备连接记录和可选的临时访问控制。

- 浏览器直接触发任务运行、停止与查看运行历史。
- 流程多选、打包成循环或条件容器。
- 自定义复用模块与跨任务复制。
