# 雕雕助手

雕雕助手是一个 Android 自动化工具，支持点击、滑动、找图、找色和 OCR。可以在手机上录制操作或编辑 JavaScript，也可以通过局域网在浏览器里拖拽编排流程。任务由安装了雕雕助手的 Android 设备运行。

## 快速开始

1. **安装 APK。** 支持 Android 10 及以上。已有任务时，卸载旧版前先[导出任务 ZIP](#备份与迁移)。
2. **开启任务需要的权限。** 到 App 的「权限」页查看状态；要用找图、找字或截图时，在「设置 → 截屏通道设置」选择并测试截屏方式。
3. **创建任务。** 到「任务」页点「＋」，填写名称后选模板。创建后会打开任务详情，由你选择下一步操作。
4. **编辑并运行。** 在 App 的「编辑脚本」里修改代码，或到浏览器的「流程编辑」里编排步骤。保存后打开悬浮任务面板，选择任务并执行。

| 能力 | 什么时候需要 |
| --- | --- |
| 无障碍服务 | 点击、滑动、手势和操作录制。 |
| 悬浮窗权限 | 打开悬浮任务面板，以及使用取点、取色、截图、录制等快捷工具。 |
| 截屏能力 | 找图、找色、OCR、截图和带画面的录制。未 Root 的设备通常选「系统授权截屏」；「超级权限截屏」需要设备授予 Root 权限。截屏通道测试通过后才会保存，不会自动切换通道。 |

App 新建任务时可选「空白」「可视化脚本」「签到模板」或「找图演示」。只想先验证点击和滑动，可以选「空白」并把示例坐标改成自己的目标位置；想从零拖拽编排，选「可视化脚本」。浏览器里也可以直接新建脚本任务或流程任务。

## 浏览器编辑

1. 在 App 打开「设置 → 局域网 Web 编辑」，点「启动服务」。
2. 用同一局域网的电脑、平板或手机，在浏览器打开 App 显示的地址，例如 `http://192.168.1.20:8765/`。地址无需附加 token。
3. 从左侧选择任务。选「脚本编辑」可修改 `task.js`；流程任务还有「流程编辑」。改完点「保存」。Web 页面保存的是 Android 设备上的任务。

同一局域网内能访问该地址的设备都可以编辑任务。请在可信网络使用，用完可回 App 点「停止服务」。

### 编排流程

- **添加和移动步骤：** 点击模块卡片，或把模块拖到插入线、循环体、条件分支。拖动步骤左侧的把手调整顺序；选中卡片后在「步骤参数」里修改设置。
- **移动和缩放画布：** 拖空白处或滚动鼠标可平移，按住 Ctrl / Command 滚动可缩放；触屏可双指缩放。底部工具栏的「适应」可查看全局，「起点」可回到流程开头。
- **设置循环和分支：** 支持顺序组、固定次数、条件成立时循环、直到满足、持续循环和条件分支。「直到满足」会在每轮循环体执行前检查条件，条件已满足时不会再执行这一轮。「退出循环」和「进入下一轮」只作用于最近一层循环。
- **设置找图和找字：** 图片可以从当前任务素材选择，也可以直接上传。条件分支、条件循环和「直到满足」也支持选图；用「全部满足」或「任一满足」组合两项条件时，两项可以分别选图。找图和找字默认「仅识别」，需要点屏幕时，在「命中后」选择「点击命中位置」。
- **预览并保存：** 「代码预览」会生成代码供查看，不会运行任务。保存流程后会生成 `task.js`。例如，要做一个「等待按钮出现后点击」的任务，可添加「找图」，选按钮模板，设置超时和轮询间隔，再把「命中后」改为点击、「未命中时」改为停止报错。

找图步骤会在超时前反复匹配，命中就提前结束；超时后的行为由「未命中时」决定。步骤里的等待和轮询间隔使用毫秒，整任务的轮次间隔使用秒。

### 编辑代码与任务设置

- App 可以直接编辑 `task.js`，并通过「示例」复制或插入代码。App 内的流程任务也能打开生成的 `task.js`；可视化编排在 Web 完成。
- **手动修改并保存流程任务的 `task.js`，任务会转成普通脚本任务。** 仅查看代码不会转换，普通脚本任务也不能反向转为流程任务。想继续拖拽编排，应在「流程编辑」页修改并保存。
- Web 的「任务设置」可修改名称、描述、目标应用包名、整任务循环和设计尺寸。填写目标应用包名后，运行时会尝试打开该应用。设计尺寸用于坐标缩放，宽和高可以一起留空。

编写 JavaScript 可参考[脚本 API](docs/script-api.md)和[任务脚本编写指南](docs/script-writing-guide.md)。

## 运行任务

- **立即运行：** 打开悬浮任务面板，长按一个任务即可单独运行；点选多个任务后点「执行所选」，会按点选顺序执行。
- **循环执行：** 在 App 的任务详情里打开「循环执行」，可按次数、按时长或一直运行到手动停止。每轮从头执行整个任务，和流程内部的循环分别设置。
- **定时运行：** 在任务详情里设置延时一次、固定间隔（至少 15 分钟）或每天固定时刻。定时启动也使用该任务的循环设置。
- **停止与排查：** 运行时可双击悬浮雕雕停止任务及剩余队列。出错时先看运行日志，再到任务详情的「运行历史」查看结果、耗时或错误详情。

悬浮任务面板里的「快捷工具」提供取点、取色、选择范围、截图和两种录制入口。「选择范围」可复制 `[x, y, 宽, 高]`，用于找图、找色或 OCR。「纯坐标录制」不需要截屏授权；需要画面辅助时用「录制操作」。录制中可暂停，点「完成」后保存任务。

## 素材管理

在 App 的任务详情或 Web 的「素材管理」中打开当前任务的图片。图片保存在任务的 `images/` 目录，脚本可用 `images/按钮.png` 这样的相对路径引用。

| 操作 | 怎么用 |
| --- | --- |
| 导入与预览 | App 可从相册或文件导入；Web 支持批量上传、缩略图、大图预览和下载。流程选图时上传的图片也会存到当前任务。 |
| 重命名 | 确认前可查看受影响的脚本引用；确认后同步更新匹配的 `task.js` 引用，流程任务也会更新相应的流程文件和草稿引用。 |
| 裁剪 | 框选要保留的区域，拖选区或四角调整，也可输入原图像素坐标。保存后以原名替换当前图片，原图进入历史素材。 |
| 移回历史素材 | App 和 Web 共用历史记录。Web 可以预览历史原图；「移回素材」会恢复原文件名，并覆盖当前同名图片。 |

## 备份与迁移

- **单个任务：** 在 App 的任务详情点「导出任务 ZIP」。
- **全部任务：** 在「任务 → 导入与导出」点「导出全部任务」。保存位置由系统文件选择器指定。
- **导入到另一台设备：** 在目标设备的「导入与导出」中选择 ZIP。支持单任务和任务合集；同名任务会跳过。

ZIP 会带上脚本、配置和素材，流程任务还会带上 `flow.json`。更换设备或卸载 App 前请把 ZIP 保存到任务目录之外。

## 常见问题

**电脑打不开 Web 编辑器。** 先确认 App 显示「服务运行中」，设备在同一局域网，并且打开的是 App 显示的 `http://` 地址和端口 `8765`。如果 Wi-Fi 隔离了设备，改用能互通的网络。

**找图或 OCR 一直没结果。** 先测试截屏通道；再确认目标页面已打开、素材在当前任务下、识别区域覆盖目标。找图时可预览模板，并适当调整匹配阈值或延长超时。

**识别成功但没有点击。** 流程里的找图、找字默认「仅识别」。需要点击时改为「点击命中位置」，并确认无障碍服务已开启。

**点击位置不准。** 用悬浮面板的取点工具重新取坐标，检查设备的分辨率、横竖屏方向，以及任务的设计尺寸是否与原脚本一致。
